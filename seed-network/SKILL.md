# Investor Network

Use for a warm introduction or to compare relationship paths. Use a private workspace with contact and investor records.

Run [the workspace CLI](scripts/seed_workspace.py) and read
[the workflow](references/workflow.md) for inputs, outputs and failure handling.
See [private venture setup](references/workspace.md) if the store is missing.
Confirm the venture, record identity and current revision before writing.
