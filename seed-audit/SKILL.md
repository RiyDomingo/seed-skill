# Venture Evidence Audit

Select the venture, review date and current evidence. Run
[the workspace CLI](scripts/seed_workspace.py), using
[the workflow](references/workflow.md) for contract and results.
Follow [private workspace setup](references/workspace.md) for new ventures.
Report evidence gaps, confidentiality restrictions and blocking findings.
